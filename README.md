# Nitish Kumar Tiwari — Personal Portfolio

A responsive, four-page portfolio website built with semantic HTML5, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — Profile and education
- `projects.html` — Selected projects
- `contact.html` — Accessible contact form demo

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Accessibility features
- Semantic landmarks: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Skip-to-content link
- Keyboard-visible focus indicators
- Descriptive page titles and meta descriptions
- Form labels, required fields, hints and live status announcement
- Responsive navigation with `aria-expanded` and `aria-controls`
- Reduced-motion preference support
- Responsive layout and readable color contrast

## Important before submission
1. Replace any profile details you want to change.
2. Add your real email and social/profile links if you want them displayed.
3. The contact form is front-end validation only; connect a backend or form service if you need to receive messages.
4. Check each page with keyboard navigation and an accessibility checker.

## Publish with GitHub Pages
1. Create a public repository on GitHub, for example `nitish-portfolio`.
2. Upload all files and folders from this project (keep the folder structure).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After GitHub publishes the site, copy the Pages URL and submit that URL to the internship portal.
